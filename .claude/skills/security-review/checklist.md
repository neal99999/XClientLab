# iOS 安全审计检查单

逐项核对，命中就记录「文件:行号 + 证据」；不适用写「N/A + 原因」。

## 1. 凭据与配置
- [ ] 源码/配置/测试里没有硬编码 AppSecret、私钥、证书口令、内网地址。
- [ ] `.env`、`.p8`、`.p12`、`GoogleService-Info.plist` 等敏感文件没有进入 git 或日志。
- [ ] `Info.plist` 没有扩大 ATS 明文放行，没有新增不必要的 URL Scheme / 权限描述。

## 2. 日志与调试
- [ ] 没有打印 token、Authorization、签名、设备指纹、用户手机号/身份证、资产与订单参数。
- [ ] 生产包关闭了调试入口（DebugTools、网络环境切换、日志面板）；`#if DEBUG` 边界正确。
- [ ] 崩溃上报/埋点没有附带敏感参数。

## 3. 传输安全
- [ ] 新增请求走现有 Provider，没有裸 `URLSession` / `NSURLConnection`。
- [ ] 域名在 SSL Pinning 证书覆盖范围内；关闭校验/信任全部证书的代码不存在。
- [ ] 代理与 MAH 线路的降级逻辑没有把普通请求也降级。

## 4. 存储
- [ ] token、刷新令牌、助记词/私钥类数据在 Keychain，不在 UserDefaults / 文件 / MMKV 明文。
- [ ] 缓存目录没有明文保存订单、资产、身份信息；必要时排除 iCloud 备份。
- [ ] 退出登录会清理 token、用户态缓存、WebView Cookie、剪贴板敏感内容。

## 5. WebView 与 JS Bridge
- [ ] 只加载白名单域名；`navigationDelegate` 校验跳转，不无条件 `allow`。
- [ ] JS Bridge 方法有来源校验与参数校验，不暴露文件读写/任意 URL 请求能力。
- [ ] `javaScriptEnabled`、`allowsInlineMediaPlayback` 等配置没有放宽到危险程度。

## 6. 深链与外部输入
- [ ] URL Scheme / Universal Link 的参数有校验（金额、地址、回调域名），不直接透传给下单/转账。
- [ ] 剪贴板读取有用户意图，不后台轮询；粘贴内容做格式校验。
- [ ] 通知、推送 payload 不包含敏感明文，点击后跳转有校验。

## 7. UI 与隐私
- [ ] 退到后台时敏感页面有遮罩/模糊，避免任务切换截图泄露。
- [ ] 截图/录屏分享不包含用户资产与身份信息。
- [ ] 权限申请文案与实际用途一致；拒绝权限后功能降级合理。

## 8. 第三方与供应链
- [ ] 新增 SDK 来源可信、版本锁定；没有 `pod 'X'` 不锁版本。
- [ ] 没有修改 `Pods/` 源码；内置源码（CHKLineChart）的改动在约定目录内。
- [ ] 第三方 SDK 初始化没有把用户标识/资产信息传给非必要方。

## 9. 业务风控
- [ ] 下单/撤单/划转有防重复提交；非幂等接口没有自动重试。
- [ ] 金额、精度、手续费的计算在前端只是展示，服务端仍校验；前端没有可绕过的「信任输入」。
- [ ] 越权：接口参数里的 userId/accountId 不可由前端任意指定。
